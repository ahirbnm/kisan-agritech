# 🌾 Kisan AgriTech

Kisan AgriTech is a simple and modern eCommerce web platform designed for farmers to buy agricultural products like seeds, pesticides, fertilizers, and farming tools online.

---

## 🚀 Features

- 🌱 Buy Seeds online
- 🧪 Pesticides collection
- 🌾 Fertilizers shop
- 🚜 Farming tools section
- 📱 WhatsApp order system
- 💻 Simple and responsive design

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

---

## 📦 How it Works

- Click on "Buy Now" button
- It redirects to WhatsApp
- Customer places order directly via chat
